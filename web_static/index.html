Run

Livestream mode scans the audio for the loudest, most animated moments (screaming, laughing, rage), transcribes only those, and has the model pick clips from them - so a 5-hour VOD doesn't have to be transcribed end to end. Twitch and YouTube VOD links both work.
Soft targets - the model aims for this range but won't discard an otherwise strong clip just for landing outside it. Only YouTube's 180s Shorts ceiling is a hard cutoff.
Generates a short spoken hook line per clip (Groq for the script, free edge-tts for the voice) and plays it before the clip's own audio - adds a few seconds per clip and needs an internet connection.

Daily Queue

Runs every video already sitting in input/ in one go, splitting a total clip target across however many videos are there, then - if you turn on uploading - posts everything produced spaced out over the day so YouTube doesn't see a burst of uploads land in the same few minutes. Uses the Whisper model, duration targets, and caption/voiceover settings above.
